แก้ demo FACEIT ที่⁠เปิด⁠แล้ว CS2 เด้ง

สำหรับ demo จาก FACEIT ที่เกมเด้งทันทีตอนสั่ง playdemo ลากไฟล์มาวาง แล้วดาวน์โหลดไฟล์ที่แก้แล้วไปเปิดในเกมได้เลย

ไฟล์ไม่ถูกอัปโหลดไปไหน ทุกอย่างทำงานในเบราว์เซอร์ของคุณ

วิธีเปิดดู demo ที่แก้แล้ว

  1. ดาวน์โหลดไฟล์ที่แก้แล้ว
  2. ย้ายไฟล์ไปไว้ในโฟลเดอร์ steamapps\common\Counter-Strike Global Offensive\game\csgo
  3. เปิด console ในเกม แล้วพิมพ์ playdemo ตามด้วยชื่อไฟล์ ไม่ต้องใส่ .dem

คำถามที่พบบ่อย

ทำไมเปิด demo FACEIT แล้ว CS2 เด้ง

ตอบสั้น ๆ: เพราะไก่ ไม่ได้ล้อเล่นนะ demo จาก FACEIT บางไฟล์บอกเกมเรื่องไก่ในแมพช้าไปนิดเดียว ตรงกับจังหวะที่เกมกำลังเตรียมทุกอย่างพอดี CS2 เลยสะดุดไก่จนเด้งตั้งแต่ demo ยังไม่ทันเริ่ม tool นี้แค่บอกเกมเรื่องไก่ให้เร็วขึ้น demo ก็เปิดได้ตามปกติ

ข้อมูลไก่มาถึงตอนที่ CS2 กำลังเตรียมทุกอย่างในแมตช์พร้อมกันพอดี พอเกมจะอ่าน ข้อมูลนั้นก็หายไปแล้ว เกมเลยเด้ง

tool นี้ย้ายข้อมูลไก่ไปไว้ตอนต้นไฟล์ แบบเดียวกับ demo ที่เปิดได้ปกติ แล้วลบข้อมูลที่ซ้ำออก ไก่ยังอยู่ครบ ส่วนตำแหน่ง การยิง kill และระเบิด เหมือนเดิมทุกอย่าง

ถ้าในไฟล์มีตัวอักษรเพี้ยนก็แก้ให้ด้วย ไม่งั้นโปรแกรมวิเคราะห์ demo บางตัวจะอ่านไฟล์ไม่ได้

รายละเอียดทางเทคนิค

เกมเด้งด้วย access violation ใน engine2.dll ที่ GetClassBaseline เพราะ DEM_Packet แรกมี svc_UpdateStringTable ที่เพิ่ม entry ใหม่ใน instancebaseline มาพร้อมกับ PacketEntities แบบ non-delta ชุดแรก tool จะต่อ entry นั้นเข้าไปใน svc_CreateStringTable ตอน signon และใน DEM_StringTables แล้วลบ update ที่ซ้ำของ instancebaseline และ AnimAssetData ออกจาก packet นั้นและจาก DEM_FullPacket ใน tick เดียวกัน และซ่อม string ใน game event ที่เป็น UTF-8 ไม่ถูกต้อง message อื่นทั้งหมดถูกคัดลอกไปแบบไบต์ต่อไบต์

รู้ได้ยังไงว่า demo มีปัญหานี้

พอพิมพ์ playdemo แล้วเกมเด้งออกทันที ตอนที่ demo ยังโหลดไม่เสร็จ ส่วนใหญ่เป็นเดโม่จาก FACEIT ถ้าไม่แน่ใจก็ลากไฟล์มาวางได้เลย tool จะตรวจก่อน และแก้เฉพาะ demo ที่มีปัญหานี้จริง ๆ

ต้องแตกไฟล์ .dem.zst ก่อนไหม

ไม่ต้อง demo ที่โหลดจาก FACEIT มักเป็นไฟล์ .dem.zst ลากมาวางได้เลย (.dem.gz ก็ได้) ถ้า demo นั้นไม่ต้องแก้ ก็ยังได้ไฟล์ .dem ที่แตกแล้วไปเปิดในเกม

ไฟล์ demo ถูกอัปโหลดไปไหนไหม

ไม่ tool แก้ไฟล์ในเบราว์เซอร์ของคุณ ไฟล์ไม่ออกจากเครื่องเลย สิ่งเดียวที่หน้านี้ส่งออกไปคือ +1 ให้ยอดรวมของ demo ที่แก้แล้ว ซึ่งเก็บไว้ที่ abacus.jasoncameron.dev โดยไม่มีชื่อไฟล์หรือข้อมูลอะไรจากไฟล์ ซอร์สโค้ดดูได้บน GitHub

แก้แล้วยังเด้งอยู่ ทำยังไงดี

ถ้า tool บอกว่าไม่ต้องแก้ หรือแก้แล้วยังเด้งอยู่ แปลว่าเกมเด้งจากสาเหตุอื่นที่ tool นี้แก้ไม่ได้ นอกจากนี้ tool จะบอกด้วยถ้าไฟล์เป็น demo ของ CS:GO ซึ่ง CS2 เปิดไม่ได้ หรือถ้าไฟล์ดาวน์โหลดมาไม่ครบ

ทดสอบกับ CS2 เวอร์ชัน 1.41.9.2 (ตุลาคม 2026) ไม่เกี่ยวข้องกับ Valve หรือ FACEIT
